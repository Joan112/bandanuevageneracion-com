# Banda Nueva Generación Digital

Construye y despliega un sitio web público, moderno, responsive y orientado a conversión para una agrupación de música regional mexicana llamada:

BANDA NUEVA GENERACIÓN

IMPORTANTE:

- NO debe existir carrito.

- NO debe existir checkout.

- NO debe existir pasarela de pago.

- NO debe existir formulario largo.

- Todos los productos/servicios deben cerrar por WhatsApp.

- Cada tarjeta debe tener su propio botón de WhatsApp con un mensaje dinámico que incluya el nombre del producto/paquete seleccionado.

- Al finalizar, despliega el sitio y proporciona la URL pública.

16. COMPORTAMIENTO WHATSAPP

==================================================

Crear una constante configurable para el teléfono:

const WHATSAPP_NUMBER = "52XXXXXXXXXX";

No hardcodear el teléfono en múltiples componentes.

Todos los botones deben construir dinámicamente:

https://wa.me/[NUMBER]?text=[ENCODED_MESSAGE]

Utilizar encodeURIComponent().

El mensaje debe incluir siempre el producto seleccionado.

Ejemplo base:

Hola 👋 Me interesa contratar a Banda Nueva Generación.

Paquete: [NOMBRE DEL PRODUCTO]

Quisiera consultar disponibilidad y recibir una cotización.

👤 Nombre:

📅 Fecha del evento:

📍 Municipio / ubicación:

⏱️ Número de horas:

¿Tienen disponibilidad para esa fecha?

Ejemplo de implementación:

const message = `

Hola 👋 Me interesa contratar a Banda Nueva Generación.

Paquete: ${packageName}

Quisiera consultar disponibilidad y recibir una cotización.

👤 Nombre:

📅 Fecha del evento:

📍 Municipio / ubicación:

⏱️ Número de horas:

¿Tienen disponibilidad para esa fecha?

`;

const whatsappUrl =

  `https://wa.me/${WHATSAPP_NUMBER}?text=${encodeURIComponent(message)}`;

Abrir en nueva pestaña.
